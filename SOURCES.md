# Sources

This repo distills the following projects, collected in [this post by @sven_ai](https://x.com/sven_ai/status/2112735477023605138). Nothing here is a copy; the procedures, thresholds and patterns were read, compared and rewritten for agent use. Where a tool is recommended, the skill says what it does and how to run it.

| Project | What it is | License | What we took |
|---------|------------|---------|--------------|
| [SEOnaut](https://github.com/StJudeWasHere/seonaut) | Self-hosted site audit crawler (Go + MySQL, Docker). Finds broken links, redirect issues, duplicate or missing meta tags, heading order problems, grouped by severity. Hosted version at seonaut.org. | MIT | Audit issue taxonomy and severity model; Docker recipe in `docker/seonaut.compose.yml`; the idea that a crawl report is the baseline for an audit. |
| [SerpBear](https://github.com/towfiqi/serpbear) | Self-hosted rank tracker (Next.js + SQLite). Unlimited domains and keywords, Search Console and Google Ads integration, email/Slack notifications, SERP scraping through providers or your own proxies. | GPL-3.0 | Monitoring workflow, scraper provider table, keyword discovery from Search Console, Docker recipe in `docker/serpbear.compose.yml`. |
| [OpenSEO](https://github.com/every-app/open-seo) | Open-source Semrush/Ahrefs alternative built around DataForSEO, with an MCP server and agent skills for keyword research, clustering, audits, competitor analysis, local SEO, link prospecting, AI visibility and reporting. | MIT | The evidence-first audit method (orient, investigate page families, shortlist, choose, size honestly, review), keyword research and clustering procedures, AI visibility audit procedure, local SEO procedure, link prospecting query patterns, report format and guardrails. |
| [SEOMachine](https://github.com/TheCraigHewitt/seomachine) | Claude Code workspace for long-form SEO content: research, write, optimize, analyze and publish, with specialized agents and 26 marketing skills. | MIT | Content guidelines (length, keyword placement, structure, meta formulas, link counts, readability), meta title and description frameworks, internal linking strategy, AEO/GEO content patterns, AI writing tells, programmatic SEO playbooks, schema markup examples, project context file idea. |
| [SoPilot](https://sopilot.net) | Growth SaaS with a Chrome extension; its SEO angle is batch submission to 200+ product and startup directories for backlinks, plus AI article generation. | Commercial | Directory submission as a repeatable backlink tactic, covered in `seo-link-building`. |
| [Awesome Open-Source SEO](https://github.com/ZensInk/awesome-open-source-seo) | Curated, tools-only list of open-source SEO software: crawlers, rank trackers, analytics, log analysis, SERP APIs, GEO tools, framework integrations, sitemaps, CLI toolkits, with recommended stacks. | CC0-1.0 | The tool landscape in `seo-tooling`, the recommended stacks, the AI crawler and `llms.txt` material. |

Further reading referenced inside the skills: Google Search Central documentation, Google Search Quality Rater Guidelines, schema.org, the `llms.txt` proposal by Answer.AI, Lighthouse and Lighthouse CI by Google Chrome.
