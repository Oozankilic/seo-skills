# Meta title and description frameworks

## Titles (about 50 to 60 characters)

Requirements: primary keyword near the start, unique across the site, honest about the page, brand at the end when it fits, no stuffing, no all caps.

Trigger elements: numbers ("7 ways", "2026 guide"), specificity ("step-by-step", "for beginners"), outcome words ("grow", "fix", "cut"), freshness ("2026", "updated"), audience ("for SaaS teams").

Five variations to generate for every page:

1. **SEO-first**: "[Keyword]: [benefit] | Brand"
2. **Benefit-first**: "[Outcome] with [method]"
3. **Question**: "[The query as a question]?"
4. **Number or list**: "[N] [adjective] ways to [benefit]"
5. **Curiosity, still accurate**: "[Unexpected angle] about [keyword]"

Report each with its character count, why it works, when to use it, and a recommendation.

## Descriptions (about 150 to 160 characters; mobile shows about 120)

Requirements: keyword, concrete benefit, a reason to click, complete sentence, ends with an action word (learn, compare, get, start, see).

Formulas:

- **Problem, solution, action**: "[Problem]? [Solution/benefit]. [Angle]. [Action]."
- **Benefit, method, action**: "[Benefit] with [method]. [Supporting benefit]. [Action]."
- **Question, answer, action**: "[Question]? [Answer preview]. [What they learn]. [Action]."
- **How-to, benefit**: "Learn how to [goal]. [Specific benefit]. [Qualifier]. [Action]."
- **Direct answer** (for AI engines): literally answer the query in the first sentence, then the angle, then the action.

Word banks by intent:
- Informational: learn, understand, find out, see how
- Commercial: compare, best, top, reviewed, pros and cons
- Transactional: start, get, try, download, book
- Navigational: official, complete, everything about

## SERP preview

Always show:

```
[Title] | Brand
example.com › blog › slug
[Description]
```

## A/B thinking

Meta changes show in Search Console click-through within two to four weeks. Change one element at a time on a page with enough impressions to measure; record the date in the project's research log.

## Red flags

Clickbait, promises the page does not keep, duplicates of another page's title, generic descriptions that fit any page, cut-off sentences, exclamation marks, keyword repeated twice in the title.
